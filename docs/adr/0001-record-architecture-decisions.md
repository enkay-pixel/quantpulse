# ADR 0001: Record architecture decisions

**Status**: accepted · **Date**: 2026-07-18

**In short:** The decisions that would be expensive to undo are written down here, one per file,
with the reasoning, so nobody has to rediscover why the project is built the way it is.

Significant design choices are captured as short Architecture Decision Records in this folder,
numbered sequentially. Each states context, the decision, and its consequences. This keeps the "why"
reviewable for a portfolio audience and for future-me.
